OrangeHRM Manual Testing

Project Overview
This project contains manual test cases created during practice testing of the OrangeHRM web application. The purpose is to practice test case design, test execution, and documenting actual results.

## Testing Scope
The following areas are covered in this project:
- Login
- Forgot Password
- Dashboard

Note: This project covers selected modules, not the entire application.

 Test Case Documentation
The Excel files contain test scenarios, test steps, test data, expected results, actual results, and execution status where applicable.

 Files Included
1. OrangeHRM-Login-Test-Cases-Final.xlsx — Login module test cases.
2. OrangeHRM-Other-Module-Test-Cases-Final.xlsx — Forgot Password and Dashboard test cases.

Testing Approach
- Functional testing
- Positive and negative test scenarios
- Input validation
- Expected versus actual result comparison

 Tools
- OrangeHRM web application
- Microsoft Excel
- GitHub

 Project Status
This is a beginner-level QA portfolio project. Test coverage is limited to the modules listed above and may be expanded with further practice.
